🚀 Project Overview

This project replaces manual inspection with an AI-driven vision inspection system capable of detecting five distinct defect types during the ABA assembly process. Each defect is handled by a dedicated trained model, ensuring high accuracy and robustness under real-time production conditions.

The solution significantly improved product quality and customer satisfaction by achieving:
- 0 customer complaints
- 0 defective products
- 100% final inspection coverage

🎯 Objectives
- Automate defect inspection on the ABA assembly line
- Reduce human error and inspection variability
- Detect defects in real time with high accuracy
- Enable automated corrective actions
- Improve product quality and customer satisfaction
